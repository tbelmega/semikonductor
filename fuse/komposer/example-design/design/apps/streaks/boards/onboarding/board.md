# Onboarding

The first screen a new user sees after installing Streaks.

## Round 1

Question: How should a new user pick their first habits?
Fidelity: mockup

### 1a: Checklist

Direction: Everything on one screen. A short list of suggested habits with checkboxes, and one button to start. Fast for people who already know what they want.

### 1b: Guided steps

Direction: Three small steps with a progress indicator: pick a goal, pick habits for it, set a reminder time. Slower, but each screen asks one thing.

### 1c: One question

Direction: A single friendly question with large answer cards. Streaks suggests the habits from the answer, and the user can change them later.
